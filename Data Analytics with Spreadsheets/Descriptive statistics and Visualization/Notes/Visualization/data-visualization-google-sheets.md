# Data Visualization in Google Sheets: Overview & Workflow

This project covers the fundamentals of data visualization, exploring how to transform raw datasets into clear, actionable charts using Google Sheets. The repository demonstrates data preparation, visual selection, and trend analysis using South African household income and expenditure data.

## 📊 Overview & Objectives

Data visualization bridges raw analytics and strategic decision-making. Key objectives covered in this project include:

- **Understanding Visualizations**: Grasping why data visualization is critical for identifying trends, patterns, and proportions.
- **Selecting Chart Types**: Choosing between composition and trend-focused charts based on the data structure and analytical goals.
- **Hands-on Implementation**: Building clean visualizations within Google Sheets using real-world datasets.
